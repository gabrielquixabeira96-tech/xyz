|  |
| :-: |

## **1.2**  **Anatomia cirúrgica que cai todo ano**   **\[Q59 · Q68\]**

|  |
| :-: |
| \*\*ð¯ O QUE CAI\*\*Três pontos anatômicos que aparecem em quase toda prova: as artérias da parede abdominal, a vascularização/drenagem do lobo caudado e as referências hepáticas (linha de Cantlie, sulco de Rouvière). |

  

### **Parede abdominal (Q59)**

  - **Artéria epigástrica SUPERIOR** = ramo da **torácica interna (mamária interna)**. É a resposta certa.
  - **Artéria epigástrica INFERIOR** = ramo da **ilíaca externa**.
  - **Linha arqueada (de Douglas):** ABAIXO dela **não existe bainha posterior do reto** — toda a aponeurose passa por anterior. (Por isso a alternativa que ‘monta’ bainha posterior abaixo da arqueada é falsa.)
  - **Nervos sensitivos da parede:** correm no plano **entre o transverso e o oblíquo interno** (o plano TAP) — não entre interno e externo.

  

### **Lobo caudado e fígado (Q68)**

  - **Lobo caudado (segmento I):** drena **direto para a veia cava inferior** (não pelas hepáticas) e recebe ramos portais **dos DOIS lados** (direito e esquerdo). É a resposta certa.
  - **Linha de Cantlie:** da vesícula à VCI; separa fígado direito do esquerdo (plano do segmento IV / V-VIII). ***Não*** fica entre IV e II/III.
  - **Veias hepáticas:** média + esquerda geralmente formam tronco comum; a direita drena separada.
  - **Sulco de Rouvière:** marca o pedículo posterior DIREITO — referência de segurança na colecistectomia.

  

|  |
| :-: |
| \*\*⚠️ A PEGADINHA\*\*\*\*Q59: você marcou o plano nervoso errado.\*\* Decore: nervo da parede = plano TAP = entre transverso e oblíquo interno.\*\*Q68: você esqueceu que o caudado recebe sangue dos DOIS ramos portais.\*\* Essa dupla irrigação é o que o protege na hipertensão portal. |

  

|  |
| :-: |
| \*\*ð§  MACETE\*\*\*\*Epigástricas:\*\* ‘a de cima vem de cima (tórax), a de baixo vem de baixo (ilíaca)’.\*\*Caudado = o ‘independente’:\*\* dois pais (portal D+E) e porta própria para a cava. |

  

|  |
| :-: |
| \*\*✅ FIXAÇÃO\*\*\*\*Epigástrica superior = torácica interna. Caudado = drena direto na cava + recebe portal bilateral. Cantlie = vesícula→VCI.\*\* |

## **1.4**  **Trauma vascular: sinais maiores vs. menores**   **\[Q40\]**

|  |
| :-: |

|  |  |
| :-: | :-: |
| \*\*SINAIS MAIORES (HARD) → operar/explorar\*\* | \*\*SINAIS MENORES (SOFT) → investigar\*\* |
|   - Sangramento pulsátil / ativo&#10;  - Hematoma expansivo ou pulsátil&#10;  - Frêmito palpável ou sopro&#10;  - Isquemia do membro (6 P)&#10;  - Ausência de pulso distal |   - História de sangramento volumoso na cena&#10;  - Pulso diminuído (mas presente)&#10;  - Ferimento próximo ao trajeto vascular&#10;  - Déficit neurológico de nervo adjacente&#10;  - Fratura/luxação próxima a grande vaso |

  

|  |
| :-: |
| \*\*⚠️ A PEGADINHA\*\*\*\*A banca mistura sinais maiores e menores na mesma alternativa para confundir.\*\* ‘Cinemática do trauma’ e ‘síndrome compartimental’ NÃO são sinais maiores de lesão vascular. |  |

|  |
| :-: |
| \*\*✅ FIXAÇÃO\*\*\*\*Hard signs (sangra/sopra/freme/isquemia/sem pulso) → cirurgia. Soft signs → investigar.\*\* |

## **2.1**  **Megaesôfago chagásico — graus de Rezende**   **\[Q71\]**

|  |
| :-: |
| \*\*ð¯ O QUE CAI\*\*A doença de Chagas destrói o plexo de Auerbach → o esôfago perde peristalse e o esfíncter inferior (EIE) não relaxa. A classificação radiológica de Rezende (graus I a IV) define dilatação e tratamento. A pegadinha mora nos detalhes do grau I e na manometria. |

  

|  |  |  |  |
| :-: | :-: | :-: | :-: |
| \*\*Grau\*\* | \*\*Calibre\*\* | \*\*Características\*\* | \*\*Tratamento\*\* |
| \*\*I\*\* | \*\*Normal (até 4 cm)\*\* | Trânsito lento, sem retenção franca | \*\*Clínico / dilatação\*\* |
| \*\*II\*\* | \*\*4 – 7 cm\*\* | Retenção franca, ondas terciárias | \*\*Heller + fundo parcial\*\* |
| \*\*III\*\* | \*\*7 – 10 cm\*\* | Grande retenção, hipotonia distal | \*\*Heller + fundo parcial\*\* |
| \*\*IV\*\* | \*\*\\\> 10 cm (dolico)\*\* | Atônico, alongado, sigmoide | \*\*Esofagectomia\*\* |

  

|  |
| :-: |
| \*\*ð O ACHADO QUE DEFINE TUDO — A MANOMETRIA\*\*\*\*Independente do grau, a manometria do megaesôfago/acalasia mostra SEMPRE:\*\*  - \*\*Falha de relaxamento do EIE\*\* (esfíncter não abre).&#10;  - \*\*Aperistalse do corpo:\*\* ondas \*\*síncronas (simultâneas) e de baixa amplitude\*\* — não-propulsivas. (Essa é a alternativa certa da Q71.) |

  

|  |
| :-: |
| \*\*⚠️ A PEGADINHA\*\*\*\*Na Q71 você marcou ‘esvaziamento normal/rápido’.\*\* ERRADO: mesmo no grau I o esvaziamento já é \*\*LENTO\*\* (há retenção). E a disfagia é o sintoma PRINCIPAL, nunca ‘rara’.\*\*A resposta certa era a manometria:\*\* ondas síncronas de baixa amplitude no corpo. Esse é o achado que você deve reconhecer de imediato. |

  

|  |
| :-: |
| \*\*ð§  MACETE\*\*\*\*Calibres por grau — ‘4-7-10’:\*\* II começa em 4, III em 7, IV passa de 10 cm.\*\*Manometria da acalasia =\*\* \*\*‘EIE travado + corpo mudo’\*\* (não relaxa + ondas síncronas fracas). |

  

|  |
| :-: |
| \*\*✅ FIXAÇÃO\*\*\*\*Acalasia/Chagas = EIE não relaxa + corpo aperistáltico (ondas síncronas de baixa amplitude). Esvaziamento sempre lento. Disfagia é o sintoma-rei.\*\* |

## **3.3**  **Trauma renal — classificação AAST**   **\[Q7\]**

|  |
| :-: |
| \*\*ð¯ O QUE CAI\*\*A graduação AAST do trauma renal define a conduta. O divisor de águas entre os graus é a PROFUNDIDADE da laceração e o ENVOLVIMENTO DO SISTEMA COLETOR (extravasamento de contraste na fase excretora). |

  

|  |  |
| :-: | :-: |
| \*\*Grau\*\* | \*\*Achado (TC com contraste, fase excretora)\*\* |
| \*\*I\*\* | Contusão OU hematoma subcapsular. SEM laceração. |
| \*\*II\*\* | Hematoma perirrenal contido. Laceração ≤ 1 cm de profundidade, SEM extravasamento. |
