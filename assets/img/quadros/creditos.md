# Créditos dos quadros

Cada ladrilho de matéria usa um recorte quadrado de uma obra dos séculos XV–XVI
em domínio público, baixada do Wikimedia Commons (miniatura padrão do
`thumb.wikimedia.org`). Todas receberam o mesmo tratamento para formar uma série:
recorte 1:1 centrado no assunto, 1200 × 1200 px, viragem para a rampa
carvão → sépia → âmbar → creme (60 % sobre o original levemente dessaturado),
vinheta suave e exportação WebP (qualidade 80; quando o grão do papel ou a
ampliação passava de 200 KB, qualidade 70–75 e um desfoque leve de 0,5–1,5 px).
Licença conferida na API do Commons
(`extmetadata.LicenseShortName`) em 9/11/2026.
